# dimp
Downloading Images and Metadata with Python is a new workshop being offered by OU Libraries. This workshop is based on the tutorial on [Accessing Images for Analysis](https://github.com/LibraryOfCongress/data-exploration/blob/master/loc.gov%20JSON%20API/Accessing%20images%20for%20analysis.ipynb) tutorial offered by the Library of Congress.

## How to Use this Repository
1. Navigate to the downloadWorkflow.ipynb file.
2. Click on the three dots (...) in the top right hand corner.
3. Click on the "Download" field to download the notebook onto your computer.
